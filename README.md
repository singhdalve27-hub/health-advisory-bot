# Health-Advisory Assistant
**Project Type:** Capstone RAG System (Local Community Assistant)
**Dataset:** DOH Health Advisories on Common Communicable Diseases

## Project Overview
This project is a Retrieval-Augmented Generation (RAG) chatbot designed to provide accurate health advisories, symptom checking, and prevention guidelines using the official DOH manual.

## Folder Structure
* `/data/` - Contains the raw PDF dataset and the ChromaDB persistent storage.
* `/docs/` - Contains the project proposal and other documentation.
* `/src/` - Contains the source code for data ingestion and the RAG pipeline.
